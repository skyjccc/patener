# 拍档大冒险 🤝

双人合作闯关手游(灵感来自《双人成行》《Pico Park》),支持两种玩法:

1. **双机联机(推荐)**:两台手机连同一个 Wi-Fi,一台创建房间(1P 阿橙·冲刺),另一台加入(2P 阿蓝·二段跳),各自用整台手机控制自己的角色;
2. **同屏双人**:一台设备横屏,两人分握左右半屏(1P 左半屏 / 2P 右半屏)。

两人配合解谜、越过陷阱,一起到达终点之门才能过关。另有 **🌋 岩浆攀爬** 无尽模式:
程序生成的登塔竞速,躲避上涨的岩浆,看你们能爬多高。

纯 HTML5 Canvas + 原生 JavaScript,**零依赖、零素材**(画面程序化绘制、音乐音效 WebAudio 实时合成),局域网 Node 服务器负责房间配对与消息转发。

## 运行

```bash
cd patener
npm install        # 首次(仅 ws 一个依赖)
node server.js     # 启动后打印局域网地址
# 手机浏览器打开控制台显示的局域网地址,例如 http://192.168.1.3:8642
```

- 手机保持竖直拿稳也没关系,游戏会提示横屏;建议「添加到主屏幕」全屏体验。
- 电脑也能玩:同一局域网任意浏览器打开相同地址。

## 合作机制一览

- **超级跳**:跳到伙伴头上再跳,高度 ×2。
- **变桥**:长按「喊」0.3 秒趴下,整条身体变成桥面让伙伴通过;按跳弹起。
- **机关板/门**:站上开门;标 ×2 的板要**两人同时站**;木箱能替你压板;拉杆扳动后锁存。
- **跷跷板**:会摇摆、会把人滑下坡——伙伴压住一端,你趁势冲上高处。
- **能力互补**:阿橙冲刺撞碎裂纹砖+空中突进;阿蓝二段跳上高台。
- **蹦床**:1.6 秒内连续弹跳充能(×2~×5),两人轮流充能能把伙伴弹上 10 格高。
- **火焰喷口**:闪烁预警后喷火;冰面打滑要提前刹车。
- 检查点重生(优先伙伴身边,防互卡)、每关 3 颗水晶。

## 双机联机怎么玩

1. 两台设备都打开游戏地址 → 点「**双机联机**」
2. 一台点「**创建房间(1P 阿橙)**」,屏幕显示 4 位房间码
3. 另一台点「**加入房间(2P 阿蓝)**」,在房间列表里点对方的房间
4. 连接成功后,房主选关卡或开启岩浆攀爬,两台设备同步开始
5. 联机时**每台手机整屏都是自己的操作区**;双方都能暂停(同步);断线有提示

联机原理:两台设备各自运行完整游戏模拟,30Hz 交换按键输入(跳跃/冲刺/呼喊用沿计数器,不丢按键),
主机每 0.5 秒广播权威状态纠偏漂移(位置软校正、机关布尔量硬同步)。局域网延迟 <5ms,手感与单人一致。
无尽模式的塔由种子确定性生成,双机自然同步。

## 合作机制

- **超级跳**:跳到伙伴头上再按跳,弹起高度 ×2,能越过单人无法跨越的深沟。
- **机关板/门**:站上(或用木箱压住)机关板开门;**拉杆**扳动后锁存。
- **能力互补**:阿橙的冲刺可以撞碎裂纹砖、空中突进;阿蓝的二段跳能上高台。
  高台机关板只有阿蓝能上去压,门下的伙伴等着就好。
- **接力电梯**:一块板控制一部电梯——你压板送我上去,我上去再压板接你。
- 检查点重生(优先重生在伙伴身边,防止互相卡关)、每关 3 颗水晶、失误计数与最佳时间。

## 8 个关卡

1. 第一次合作(移动/跳跃/超级跳) → 2. 按下机关(机关板/箱子/拉杆) → 3. 疾风冲刺(冲刺/裂纹砖/尖刺) → 4. 空中接力(弹簧/升降台) → 5. 齿轮走廊(电锯/时机) → 6. 双人升降(接力电梯) → 7. 黄昏钟楼(综合考验) → 8. 星空之巅(终章登顶)

## 加关卡(数据驱动,改一个文件)

编辑 `src/game/levels.js`,往 `LEVELS` 数组追加一个对象即可,选关界面自动生成:

```js
{
  name: '我的新关', theme: 'meadow',        // 主题见 themes.js,也可新增
  doorH: 3,                                  // 可选:门高(格)
  map: [                                     // ASCII 地图,详见文件头图例
    '............',
    '...1.2....E.',                             // 出生点 1/2、终点 E 必须有
    '############',
  ],
  objects: [                                 // 复杂对象
    { type: 'platform', x: 5, y: 3, w: 2, dx: 4, dy: 0, period: 3 }, // 巡逻平台
    { type: 'saw', x: 8, y: 4, dx: 3, period: 2.4, phase: 0.5 },     // 电锯
    { type: 'hint', x: 2, y: 2, text: '提示气泡' },
  ],
}
```

图例:`#` 实心 `=` 薄板 `%` 裂纹砖 `^` 地刺 `O` 木箱 `J` 弹簧 `a/b/c` 机关板
`A/B/C` 门 `l/k/m` 拉杆 `F` 检查点 `G` 水晶 `E` 终点 `1/2` 出生点

写完跑校验(行宽/必要元素/机关配对 + 带标尺打印地图):

```bash
node tools/check-levels.mjs
```

## 代码结构

```
index.html            页面外壳 + 全部 UI 样式(DOM 菜单层)
server.js             ★ 局域网服务器:静态托管 + 房间配对 + 消息中继(ws)
src/
  main.js             主循环(固定步长物理 60Hz)、状态机、联机流程、调试钩子
  core/
    input.js          触屏摇杆/按钮(同屏双人 + 联机单角色两种布局)、双人键盘、远端输入注入
    net.js            联机客户端(房间创建/加入、输入 30Hz、状态同步)
    audio.js          WebAudio 双轨 BGM(明快大调/神秘小调)+ 合成音效(无素材)
    camera.js         双人取景摄像机(中点跟随/自动缩放/震屏)
    particles.js      尘土/爆裂/纸屑/环境粒子
    save.js           localStorage 进度(解锁/水晶/最佳/失误/高度/帽子)

  game/
    constants.js      尺寸与手感参数(调手感只改这里)
    levels.js         ★ 关卡数据 12 关 + 目标时间(加关卡改这里)
    endless.js        ★ 无尽模式「岩浆攀爬」种子生成器
    level.js          ASCII 解析 + 静态地形预渲染
    entities.js       木箱/门/平台/电锯/跷跷板/火焰/蹦床 + 机关绘制
    player.js         玩家物理手感(土狼时间/跳跃缓冲/变桥)与角色绘制(帽子)
    world.js          碰撞、机关联动、胜负、岩浆、场景渲染、联机状态序列化
    themes.js         各关配色主题(10 套)
  ui/ui.js            DOM 界面流转
tools/check-levels.mjs  关卡数据校验器
```

## 性能与适配

- 静态地形一次性预渲染到离屏画布,每帧仅一次 `drawImage`;粒子池上限 420。
- 逻辑固定 60Hz 步长,渲染跟随 rAF;后台自动暂停。
- 适配刘海屏(safe-area)、竖屏提示旋转、DPR 高清渲染、触屏 `touch-action: none` 防误触。
- iOS 首次触摸解锁音频;震动反馈(支持的设备)。
